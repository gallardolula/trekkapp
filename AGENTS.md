# Expo

Este proyecto usa Expo SDK 58. Antes de escribir código, leé la documentación
versionada en https://docs.expo.dev/versions/v58.0.0/ en lugar de la genérica,
porque la API cambia entre versiones.

La versión del SDK debe coincidir con la que soporta Expo Go en el dispositivo
de prueba. Expo Go admite un único SDK a la vez, el más reciente.
