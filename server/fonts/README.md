# Glyphs

Signed distance field glyphs, which is how MapLibre draws the labels of a
vector map. A tile carries where a name goes and what it says; the shapes of
the letters have to come from here. Without them the map renders no text at
all, and reports no error while doing it.

Only two faces and two ranges are kept, 416 KB in all. Ranges `0-255` and
`256-511` cover Latin and Latin Extended-A, which is every character the
place names of the Sierras de Córdoba use. A range that is not here is
answered with a 404, which is what MapLibre expects for a range it does not
need.

They are committed rather than fetched at build time, because the server has
to be able to serve them wherever it is deployed and a map without labels is
not a map.

## Where they come from

Generated by the OpenMapTiles project from Google's Noto Sans, taken from
`noto-sans.zip` of https://github.com/openmaptiles/fonts/releases/tag/v2.0
and reduced to the four files above.
